SinglePDF Alpha Sample

This fixture exists to exercise the current Rust alpha pipeline from HTML parsing through PDF generation.

What It Includes

The current renderer focuses on semantic extraction and searchable text output rather than browser-perfect visual fidelity.

  • Headings and paragraphs
  • List items
  • Image placeholders
  • Table placeholders
